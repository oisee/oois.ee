Graded versus flat bias on an 8 GB card

i5: RTX 2070 8 GB, PCIe 3.0, full IQ2_XS 512 experts, expert cache 3.5 GB, pinned memory, -ub 512, no MTP. The graded bias is max(cap, ln(b / b_edge)) on the cold set: experts just below the hot-set edge are barely penalised, the deep tail gets the cap.

Graded versus flat at matched strength on 2×16 GB

i7: two RTX 4060 Ti 16 GB, full IQ3_S 512 experts, expert cache 17 GB, MTP drafts, -ub 512, pinned memory. Four arms in one session with flags identical to the reference run. The graded cap −1 has a mean penalty of −0.80, matching the flat −0.75, so the difference comes from the grading itself.

Agent tasks on the full model at home

Full IQ3_S 512 on i7, flat bias −0.75, MTP, Claude Code harness at xhigh effort, time limits ×5, graded by hidden tests. Bar length is wall time. osg-l0-body-003 is excluded from SMOKE: no model has solved it.

Same tasks: flat −0.75 vs graded cap −1

The same 11 SMOKE tasks, the same server and harness, only the bias file changed. Both arms solved 11 of 11. Grey bars are flat −0.75, teal bars are graded cap −1. Two flat times are missing because those runs shared the server.

The home model, with every expert kept and the graded bias, solved the task that half of the cloud models and our own K192p cut fail. L3b is the hardest; so far only Opus, GLM-5.3 in Claude Code and K192p have solved it. Its run is in progress.

8 GB card, own model (i5: IQ2_XS, graded PB3-64 cap −2, 64K context): L1a solved in 45 min. L1b failed after 52 min, but not on the model: Claude Code stopped with "autocompact thrashing". The 64K context refilled to the limit three times right after compaction, while the agent read large files. The 8 GB setup needs a larger context, or the agent needs smaller tool outputs.
